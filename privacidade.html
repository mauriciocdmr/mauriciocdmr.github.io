Política de Privacidade — Estudei Saúde

Última atualização: 19 de novembro de 2026.

Estudei Saúde é uma extensão de navegador de uso pessoal, feita para um único usuário: o próprio autor. Esta página descreve quais dados ela usa e o que faz com eles.

Dados do Google

A extensão pede uma única permissão de API do Google, gmail.send, além da identificação básica da conta (openid e e-mail), usada apenas para confirmar que a conta autorizada é a esperada. Com essa permissão, a extensão só envia e-mails em texto puro da conta do usuário para outro endereço do próprio usuário. Ela não lê, não pesquisa, não apaga e não altera mensagens nem nenhum outro dado do Gmail.

Dados de estudo

A extensão lê, no site Estudei e com o login que o próprio usuário já tem lá, o histórico das sessões de estudo: identificador, horários, duração, matéria e tópico. Esses dados vão apenas no corpo dos e-mails descritos acima. O token de login do Estudei nunca é copiado, gravado ou enviado.

Armazenamento

A configuração, a lista de sessões já processadas e a autorização do Gmail ficam guardadas localmente no navegador do usuário. Nada é enviado a servidores do autor ou de terceiros. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Revogação

O usuário pode revogar a autorização a qualquer momento pelo botão "Desconectar" da extensão ou em myaccount.google.com/permissions. Remover a extensão apaga os dados guardados localmente.
